# Documentation guide

- **Implementing:** read the assigned phase plan and relevant source. Search older
  reports only to resolve a particular question.
- **Results:** each `phase-N-result.md` keeps the delivered decisions, material
  deviations and their disposition, final checks, remaining gaps and evidence path.
  Later fixes replace stale status instead of appending another full history.
- **Evidence:** raw logs, transcripts, captures and intermediate measurements belong
  in `C:/Temp/tandem`. Keep only useful final summaries in the repository.
- **Plans:** carry forward only facts the next implementer needs. Do not require
  reading every earlier report or repeat the entire verification history.
